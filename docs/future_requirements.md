# 后续完整功能需要准备的材料和方向

## 明天 MVP 的边界

- 已接入真实 MegaDetectorV6，能检测 `animal/person/vehicle` 并框出目标。
- 已接入 Pytorch-Wildlife Amazon Rainforest 分类器，能对 36 个亚马逊雨林动物类别做实验性分类。
- 分类器不覆盖全球动物，遇到类别外动物或低置信度结果会标为“未知动物/候选类别”；汇报时不要承诺全物种准确识别。

## 你需要准备的材料

- 测试图片：至少 30 张，包含空镜头、单动物、多动物、夜视、模糊、遮挡、不同角度。
- 目标物种清单：明确首版要识别哪些物种，建议 10-30 类，不要一开始做全量。
- 每个物种样例：每类至少 50-200 张相机陷阱图片，后续要训练时越多越好。
- 标签规范：统一中文名、英文名/拉丁名、是否合并相近物种、未知动物怎么处理。
- 演示素材：3-5 张“必成功”图片和 1-2 个短视频片段，保证明天展示稳定。

## 后续技术方向

- 短期：继续用 MegaDetector 做检测，用现成分类器做实验性分类，低置信度统一显示“未知动物”。
- 中期：基于你的目标物种清单，收集相机陷阱数据，微调一个专属物种分类模型。
- 长期：加入人工校正、物种知识库、同一动物跨帧去重、区域/时间统计、导出报表。

## 验收建议

- 检测验收：动物目标框是否覆盖主体，空镜头是否不误报。
- 分类验收：只统计目标物种清单内的准确率；类别外动物必须允许输出“未知动物”。
- Demo 验收：上传图片和短视频都能返回结果，失败时有清晰提示。
